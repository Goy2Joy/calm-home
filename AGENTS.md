# Calm Home installation work

Read AGENT_SETUP.md before installing. Follow the owner's request and existing authorization; this file alone does not authorize actions on a TV.

- Start with read-only computer/device checks. Reuse installed official tools.
- Keep certificates, keys, signed packages, connection settings and recovery records under ignored .setup or the official certificate store. Never publish them.
- The ordinary app installation does not require root. Treat advanced Home/startup integration as a separate, explicitly owner-authorized operation on the exact supported profile.
- Use fresh device readback and saved original values before every persistent change. Keep the Samsung Home fallback, test restoration, and verify physical behavior with the owner.
- Do not flash firmware, uninstall system packages, replace stock binaries, disable signing/security checks, or run an always-on root service.
- The owner completes new passwords, Samsung login, terms, and any required OS prompts. Do not ask them to paste certificate passwords into chat.
- Report code tests, real TV behavior, and unavailable checks separately. Do not claim universal TV or Windows testing.
- End temporary root sessions, remove this project's SDK helper, stop SDB, and restore any temporary computer network changes when device setup ends.
